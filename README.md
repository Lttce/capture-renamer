# capture-renamer

フォルダを監視し、新しく作られたファイルを自動リネームします。

リネーム形式: `{prefix}_{連番}_{元のファイル名}.{拡張子}`

例:
- `20250720_220101.png` → `test01_01_20250720_220101.png`
- `20250720_220201.jpg` → `test01_02_20250720_220201.jpg`
- `20250720_220201.jpg` → `test01_02_20250720_220201 (1).jpg` ← 同名ファイルが既にある場合

先頭の文字列（`test01` の部分）は途中で変更でき、変更すると連番もリセットされます。
スクリーンキャプチャの連続撮影や、試験画像の収集に便利です。

## 使い方

capture-renamer

起動中に Enter を押し、新しい文字列を入力すると連番がリセットされて切り替わります。

## オプション

| 項目 | 初期値 | 説明 |
|---|---|---|
| -folder | . | 監視するフォルダ |
| -prefix | item | ファイル名の先頭に入る文字列 |
| -interval | 300 | チェック間隔(ms、100以上) |

## ビルド

go build -o bin/capture-renamer.exe .

ファイル1つで動きます。インストール不要。
